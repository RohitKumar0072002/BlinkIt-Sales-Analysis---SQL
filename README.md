# Blinkit Sales Analysis using SQL

## Overview
This project focuses on analyzing Blinkit retail sales data using MySQL. The objective is to extract meaningful insights related to product performance, outlet distribution, and overall sales behavior.

---

## Dataset
- ~8,000+ records  
- 16 product categories  
- Attributes: Item Type, Sales, MRP, Outlet Type, Location, Size, Visibility  

---

## Tools & Technologies
- MySQL  
- SQL (Window Functions, Aggregations, Filtering)

---

## Key Analysis Performed
- Category-wise sales analysis  
- Outlet type and location performance  
- Average vs Total sales comparison  
- Deviation analysis using window functions  
- Top & Bottom performing categories  

---

## Key Insights
- Top 5 categories contribute ~60%+ of total sales  
- Sales performance varies significantly across outlet types  
- Tier 3 locations show higher sales contribution  
- Some categories consistently underperform  

---

## Conclusion
Sales are highly concentrated and influenced by category demand and outlet strategy rather than uniform distribution.
